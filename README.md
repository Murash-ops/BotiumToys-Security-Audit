# BotiumToys-Security-Audit
This is a simple security audit for Botium Toys.

## What's Inside

**Security Checklist:** A list of security things like firewalls, passwords, and encryption.

**Compliance List:** Checking if the company follows important rules like PCI DSS and GDPR.

**Recommendations:** Some ideas on how to make security better.

Since I'm learning, these are just my beginner thoughts:

1. Only give people access to what they need 

2. Use an Intrusion Detection System (IDS) to catch hackers

3. Make passwords harder to guess and store them safely

4. Encrypt data so it's not easy to steal

5. Regularly check and update security measures
